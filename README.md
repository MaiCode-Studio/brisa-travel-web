# 🌴 Brisa Travel - Landing Page Demo

Este repositorio contiene la maquetación y diseño web para **Brisa Travel**, una agencia ficticia especializada en turismo y viajes grupales a través de Venezuela. El proyecto fue desarrollado como una demostración de interfaz de usuario (UI) y desarrollo web.

> ⚠️ **Nota:** Toda la información presentada en esta página (como servicios, tarifas y direcciones de sedes) es **estrictamente ficticia** y ha sido creada únicamente con fines educativos y de demostración para portafolio.

---

## 🚀 Características
* **Sección Sobre Nosotros:** Presentación concisa de la marca ficticia.
* **Viajes Grupales y Corporativos:** Sección adaptada para ofertas de *team building* y convenciones.
* **Muestra de Ubicación:** Estructura para mostrar la sede y datos de contacto de prueba.
* **Diseño Responsivo:** Adaptado para una navegación fluida en dispositivos móviles y de escritorio.
